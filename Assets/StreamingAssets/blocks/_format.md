# 方块定义文件格式

这个目录里每个 `.json` 文件定义一种方块。**加新方块不需要改任何代码**：
复制一个现有文件，改个名字和贴图，再把贴图 PNG 放进 `textures/` 就行。

## 一个完整的例子

```json
{
  "id": "grass",
  "displayName": "草方块",
  "numericId": 3,
  "textures": { "top": "grass-top", "bottom": "dirt", "side": "grass-side" },
  "solid": true,
  "opaque": true,
  "lightEmission": 0,
  "hardness": 1.0
}
```

## 字段说明

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | 字符串 | **是** | — | 唯一标识，只用小写字母和连字符。存档里记的是它，**定了就别改** |
| `displayName` | 字符串 | 否 | 同 `id` | 显示给玩家看的名字，可以用中文 |
| `numericId` | 整数 | 否 | 自动分配 | 见下方「关于 numericId」 |
| `textures` | 对象 | 是（空气除外） | — | 见下方「贴图写法」 |
| `solid` | 布尔 | 否 | `true` | 是否阻挡玩家。水和空气为 `false` |
| `opaque` | 布尔 | 否 | `true` | 是否挡光。为 `true` 时相邻面会被剔除不渲染 |
| `lightEmission` | 整数 | 否 | `0` | 自身发光强度，**只能填 0–15**。火把之类填 14 |
| `hardness` | 小数 | 否 | `1` | 挖掘耗时基准（秒）= **达标镐**挖它的时间（spec §1「挖掘时间（对应镐）」列）。等级不够时 ×4（徒手挖石 4s）。**填负数表示挖不动** |
| `minToolTier` | 整数 | 否 | `0` | 挖掉该方块所需的最低镐等级（m10 工具门槛）：0 徒手 / 1 木镐 / 2 石镐 / 3 铁镐 / 4 钻石镐，与物品表 `toolTier`（只有镐写）同尺度。**等级不够时挖得掉方块但不掉落**。负数会报错 |
| `liquid` | 布尔 | 否 | `false` | 是否为液体 |

## 贴图写法

`textures` 有两种写法，二选一：

**六面都一样**：

```json
"textures": { "all": "stone" }
```

**顶面、底面、侧面各不同**：

```json
"textures": { "top": "grass-top", "bottom": "dirt", "side": "grass-side" }
```

用第二种写法时，`top`、`bottom`、`side` **三个都必须写**，只写一两个会报错——
因为那样会留下没有贴图的面。

贴图名对应 `textures/` 目录下的文件名，**不带 `.png` 后缀**。
比如 `"stone"` 对应 `textures/stone.png`。

## 关于 numericId

方块在存档里是按数字存的，`numericId` 就是这个数字。

- **内置方块**（现在这 7 个）显式指定了 0–6，因为世界生成代码里写死了这些值，不能变
- **新加的方块**可以**不写这个字段**，系统会从 1000 开始按 `id` 字母顺序自动分配

自动分配按字母排序，所以不管文件读取顺序如何，同一批方块得到的 ID 永远一样。

## 空气是特例

`air.json` 没有 `textures` 字段，因为它没有任何可见的面。这是唯一允许省略贴图的方块。

## 改完怎么验证

在项目根目录运行：

```powershell
dotnet test
```

`BlockDefinitionFilesTests` 会检查所有定义文件能否正确解析、ID 有没有冲突、
引用的贴图是不是都已经提了需求。打错字会立刻报错，不用等进游戏。

## 常见错误

| 现象 | 原因 |
| --- | --- |
| 报「缺少 textures 字段」 | 非空气方块必须有贴图 |
| 报「textures 不完整」 | 用了 `top`/`bottom`/`side` 写法但没写全三个 |
| 报「numericId 重复」 | 两个文件用了同一个数字 |
| 报「lightEmission 必须在 0–15」 | 发光强度只有 16 级 |
| 报「不是合法的 JSON」 | 多半是少了逗号，或者多了个尾随逗号 |
