# 剪刀（shears）

## 用途

评审 08 F2 内容契约兑现：任务链 ch2_01 文案已向孩子承诺「剪羊毛」，剪刀是牧场闭环
（喂 → 繁 → 剪）的工具。手持剪刀右键准星内的羊 → 掉 1-2 羊毛，羊进入 120 秒剪毛冷却
（冷却不进存档——重进世界羊毛"长回来"，MC 同款语义）。

## 规格

| 项 | 值 |
| --- | --- |
| 最终尺寸 | 32 × 32 像素 |
| 生成尺寸 | 程序占位直接 32×32（确定性哈希） |
| 平铺 | 物品图标无需平铺 |

| 构图 | X 形交叉双刀 + 中心黄铜铆钉 + 底部指孔横杆 |
