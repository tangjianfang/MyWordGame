# m10 批量 · 4 张材料物品贴图（程序占位）

## 背景

milestone-10 A1 新增四个材料物品（挖四矿石掉落进背包）：
raw_gold / raw_iron / summer_alloy / machine_essence。
它们的 `texture` 名在 `items/textures/` 没有 PNG，实机热键栏/物品栏会显示
品红占位块（m6 批同款问题）。其中 **raw_gold / raw_iron 是进阶链第二环的
必得品**（铁镐挖到金矿/粗铁矿的第一份收获），必须先有图。

本批全部为**程序占位**（`art/scripts/gen_m10_item_placeholders.py` 确定性生成），
不是正式美术。正式图到位后按本文件调色板逐张替换即可。

## 通用规格

| 项 | 值 |
| --- | --- |
| 最终尺寸 | 16 × 16 像素 |
| 平铺 | 否 |
| Alpha | **有**（仅 0 / 255，透明背景） |
| 生成方式 | ASCII 形状 + 整数哈希铺色（与 m6 批同模式） |
| 保留色 | 不出现 `#FF00FF` |

## 逐张清单与语义色板

底色为评审指定值，暗/亮阶按底色派生（约 ×0.75 / ×1.2）：

| 名称 | 物品 | 造型 | 色板 |
| --- | --- | --- | --- |
| raw_gold | 粗金 | 不规则矿块 + 左上高光 + 右下暗边 + 两粒碎金 | 金 `#E8C04A`/`#C09A34`；高光 `#F7E08A`/`#FFEFA8`；暗 `#A8842E` |
| raw_iron | 粗铁 | 同族矿块造型（错位剪影辅助区分）+ 一粒碎屑 | 褐灰 `#8A7A6A`/`#6E6154`；高光 `#A69684`/`#B8AA9A`；暗 `#5A4F45` |
| summer_alloy | 夏季合金 | 梯形合金锭：亮顶面 + 主色锭身 + 暗底缘 | 青蓝 `#4A9AB8`/`#35758E`；顶 `#78C2DC`/`#9AD8EA`；底 `#2A5F75` |
| machine_essence | 机元 | 菱形发光核心 + 上下电路引脚，核内高光 | 紫灰 `#7A5A9A`/`#5E4478`；辉光 `#9C82BC`/`#B9A2D4` |

四张并排要能一眼分队：金最亮最黄、铁最浊、合金是「金属锭」且偏蓝、
机元是「能量核心」不是锭（造型语义即材料用途：前两种是粗料、第三种是
成型合金、第四种是神秘物质）。
