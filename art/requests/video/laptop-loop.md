# laptop-loop

笔记本/黑客电脑方块屏幕面视频（`Assets/StreamingAssets/video/laptop-loop.mp4`）。
VideoScreenSystem 把它贴到 `laptop-screen` 贴图槽的共享材质 mainTexture 上。

## AI 提示词
```
Close-up of a retro pixel-art computer screen playing green falling code rain on dark navy background, retro terminal text scrolling, subtle scanline flicker. Flat 2D screen content filling whole frame, pixel art style, no bezel, no desk, no hands, no text overlays outside the screen content, loop friendly.
```
