# P-01 玩家皮肤

## 用途

玩家角色的贴图。第一人称下只看得到手臂，但第三人称视角（按 F5 切换）和将来的多人模式
都需要完整的角色。

## 采用 Minecraft 标准皮肤布局

不自创布局，直接用 Minecraft 的 64 × 64 皮肤规范。好处：

- 网上有海量现成皮肤可以给小孩挑，替换一个 PNG 就换装
- 模型的 UV 映射是公开且固定的，我们照抄即可，不用自己排 UV
- 小孩自己画一张皮肤就能进游戏，这是最容易获得成就感的一环

## 规格

| 项 | 值 |
| --- | --- |
| 最终尺寸 | 64 × 64 像素 |
| 生成尺寸 | **不用 AI 整张生成**（见下） |
| 平铺 | 否 |
| Alpha | 有，仅 0 或 255 |
| 颜色数 | 12 – 20 色 |

## 为什么这张不交给 AI 整张生成

皮肤图不是一张「图画」，而是**一张展开的 UV 贴图**——64×64 的画布被切成几十个矩形，
每个矩形对应模型上的一个面，位置精确到像素。AI 生成的是「一个人物的样子」，
不可能对上这套布局，产出必然错位。

**正确做法**：

1. 用 Minecraft 皮肤模板（网上搜 `minecraft skin template 64x64`，或在
   [minecraft.net](https://www.minecraft.net) 的皮肤编辑器里导出一张）作为底
2. 在模板上**逐区域填色**，每个区域是纯色 + 简单的明暗
3. AI 只用来做**配色参考**：让它画一张人物立绘，从立绘里取色，再手工填到模板上

## 布局（64 × 64，像素坐标从左上角起算）

第一层（不透明主体）：

| 部位 | 区域 |
| --- | --- |
| 头 | (0,0) 起 32 × 16 |
| 躯干 | (16,16) 起 24 × 16 |
| 右臂 | (40,16) 起 16 × 16 |
| 左臂 | (32,48) 起 16 × 16 |
| 右腿 | (0,16) 起 16 × 16 |
| 左腿 | (16,48) 起 16 × 16 |

第二层（帽子/外套等覆盖层，带透明）：

| 部位 | 区域 |
| --- | --- |
| 帽层 | (32,0) 起 32 × 16 |
| 躯干外层 | (16,32) 起 24 × 16 |
| 右臂外层 | (40,32) 起 16 × 16 |
| 左臂外层 | (48,48) 起 16 × 16 |
| 右腿外层 | (0,32) 起 16 × 16 |
| 左腿外层 | (0,48) 起 16 × 16 |

**第一批不做第二层**，全部留空（Alpha = 0）。留空不影响渲染，将来想加帽子再补。

## 视觉描述

- **脸**（头部前面，即 (8,8) 起 8 × 8）：两只 1×2 的眼睛，眼白 + 眼珠；
  嘴用 1–2 像素的暗色短线；不要画鼻子（8×8 里画鼻子会变成一个脏点）
- **头发**：覆盖头顶、后脑、两侧，前额留 1–2 像素刘海
- **躯干**：上衣纯色，中央画一条 1 像素的暗色竖线当拉链或衣襟
- **手臂**：上部是上衣色，**最下面 4 像素是皮肤色**（露出的手）
- **腿**：上部裤子色，**最下面 3 像素是鞋色**
- 每个部位的**右侧和下侧各压暗一档**，做出简单的体积感
- 不要画文字、logo、图案

## 后处理

1. 下载官方 64 × 64 皮肤模板，确认布局与上表一致
2. 按「视觉描述」逐区域填色（用取色参考的配色）
3. **所有第二层区域填为 Alpha = 0**
4. 检查第一层区域内**没有任何透明像素**（第一层透明会让模型破洞）
5. 存为 32 位 PNG

## 验收标准

- [ ] 尺寸恰为 64 × 64
- [ ] 32 位 PNG，Alpha 只有 0 和 255
- [ ] 第一层的 6 个区域内 Alpha 全部为 255，无破洞
- [ ] 第二层的 6 个区域 Alpha 全部为 0
- [ ] 颜色全部落在调色板内
- [ ] 把皮肤贴到标准 Minecraft 模型上预览，脸在正面、鞋在脚上、没有部位左右颠倒
- [ ] 第一人称低头看手臂时，看到的是手臂色而不是躯干色
- [ ] 8 岁小孩能一眼说出「这是个穿蓝衣服的人」
