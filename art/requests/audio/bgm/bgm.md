# BGM 三首（bgm-menu / bgm-day / bgm-night）

氛围钢琴，跨界沙盒游戏三态背景音乐。无缝循环、各 15s+。

### bgm-menu
主菜单 BGM：开场欢迎、温暖、乐观、轻快。

## AI 提示词
```
Gentle ambient piano intro theme for a cozy voxel sandbox game. Warm, welcoming, optimistic melody with soft dynamics. Sparse notes with lots of space between them. Pure instrumental, no drums, no vocals, no percussion. Seamless loop friendly, minimal buildup.
```

## 参数
- 循环: 是
- 响度: -18
- 声道: stereo
- 时长下限: 15
