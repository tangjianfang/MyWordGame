# 环境循环（amb-birds / amb-crickets / amb-cave）

三类场景氛围：白天鸟鸣 / 夜晚虫鸣 / 洞穴水滴回响。

### amb-birds
白天乡村：鸟鸣 + 轻风 + 远风。无音乐、无旋律。

## AI 提示词
```
Daytime countryside ambience: soft bird calls, gentle breeze through leaves, distant subtle wind. Natural, calm, quiet background texture with no music and no melody. No human voices. Seamless loop friendly.
```

## 参数
- 循环: 是
- 响度: -18
- 声道: stereo
- 时长下限: 15

### amb-crickets
夜晚乡村：稳定蟋蟀鸣叫 + 远虫声。无音乐。

## AI 提示词
```
Night countryside ambience: steady cricket chirping, very quiet night air, occasional distant insect sounds. Calm natural background texture, no music, no melody. Seamless loop friendly.
```

## 参数
- 循环: 是
- 响度: -18
- 声道: stereo
- 时长下限: 15

### amb-cave
地下洞穴：远处水滴 + 低沉气流感 + 空远回声。安静神秘。

## AI 提示词
```
Underground cave ambience: echoing water drips far away, low rumbling air movement, hollow distant echoes. Quiet, mysterious, not scary. No music, no melody. Seamless loop friendly.
```

## 参数
- 循环: 是
- 响度: -18
- 声道: stereo
- 时长下限: 15
