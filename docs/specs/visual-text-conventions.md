# 视觉的文本表达规范

本项目不产出视觉稿、不使用浏览器原型。所有画面相关的设计一律用文本表达，便于父子讨论、
纳入版本管理，也便于直接转成代码参数。

## 三种表达方式

### 1. ASCII 示意（用于空间与结构）

由 `tools/dotnet/MyWorld.Preview` 直接从真实生成数据渲染，不是手绘：

```powershell
dotnet run --project tools/dotnet/MyWorld.Preview          # 默认种子
dotnet run --project tools/dotnet/MyWorld.Preview 12345    # 指定种子
```

输出四部分：纵向剖面（y=-24 起下探到矿层）、俯视高度图、地下矿层统计、贪心网格压缩比。

**方块字形约定**（剖面图）：

| 字符 | 方块 | 字符 | 方块 |
| --- | --- | --- | --- |
| `"` | 草方块 | `~` | 水 |
| `.` | 泥土 | `:` | 沙 |
| `#` | 石头 | `_` | 基岩 |
| `*` | 雪方块 | | |
| `$` | 金矿石 | `%` | 粗铁矿石 |
| `&` | 夏季合金矿石 | `@` | 机元矿石 |
| （空格） | 空气 | | |

**高度渐变字形**（高度图，由低到高）：`  .:-=+*#%@`

### 2. 画面描述（用于观感）

用文字写清玩家实际看到什么，每条都要可落地为参数。例如：

> 第一人称视野 FOV 70°，相机位于玩家脚底以上 1.62 格。
> 天空自地平线的浅青 `#BFD8EF` 渐变到天顶的饱和蓝 `#4A7FD4`。
> 距离雾从 10 区块处开始、到 14 区块处完全遮蔽，颜色与地平线一致以隐藏加载边界。
> 准星指向的方块显示 2px 黑色描边，破坏进度以 10 阶裂纹贴图覆盖。

避免"看起来更好看""更有氛围"这类无法验证的描述。

### 3. 参数表（用于实现）

任何颜色、尺寸、时长、曲线都写成具体数值，可直接复制进代码或 JSON 配置。

## 与孩子讨论时的用法

ASCII 剖面图是主要沟通媒介：改一个生成参数，重跑预览，两张图并排对比，
孩子能直接看懂"山变高了""水变多了"，不需要等 Unity 出画面。
