# milestone-9 设计：战斗手感与打猎闭环

> 日期：2026-08-16
> 状态：已通过设计评审（父子共同开发项目）
> 前置：milestone-8 已完成，dotnet 473 / EditMode 813 全绿
> 诊断报告：`.superpowers/m9-diagnosis.md`（三断环全部有 file:line 证据）

## 背景与问题

实机反馈「无法攻击猪牛、可玩性差」。诊断：**打猎→掉肉→吃的生存闭环断在三个环**：

| 断环 | 根源（诊断报告详见） |
| --- | --- |
| ① 空手/无武器不能攻击 | 攻击被「选中物品 attackDamage>0」门禁（`CombatController.cs:53-54`）——开局只有木板，左键对动物完全无效 |
| ② 追不上动物 | 动物惊跑 5m/s > 玩家走速 4.3m/s、惊跑半径 8m > 攻击距离 4m；`FleeingFromAttacker` 状态从未被赋值 |
| ③ 打死不掉肉 | `CombatController.cs:100-107` 直接置 Dying，绕过 `MobAI.Tick:54` 的 LastDrops 写入——拾取/吃肉两端已通，只缺这一环 |

另有击退/命中音效/击杀经验/死亡反馈全部缺失。

## 目标

空手能打、动物能追、打死掉肉——**挖→合→打猎→吃** 生存闭环全通，且打起来有手感（闪红/击退/音效/经验）。

## 非目标（YAGNI）

- 弓箭/远程、Boss、格挡、连击系统、攻击动画（挥手借用挖掘既有表现）
- 生物仇恨/AI 大改（只加「受击逃跑 3 秒后停」）
- PvP、伤害类型（物理/魔法）

## 1. 攻击基础（修断环①）

- **空手可攻击**：基础伤害 1；持武器用武器 `attackDamage`（items/*.json 实际字段为准：木剑 4 / 石剑 5 / 铁剑 6 / 钻石剑 7 一带——实现时逐个核对）
- **判定**：左键 + 准星射线 4m 内最近 mob（复用挖掘的 `VoxelRaycaster`/相机射线模式，**mob 优先于方块**——准星指 mob 时攻击、指方块时挖掘，同键直觉分流）
- **攻击冷却 0.5s**（防连点秒杀）；攻击与挖掘互斥同帧只触发其一

## 2. 动物可猎杀（修断环②）

- **受击才逃**：`MobAI` 的 Passive 分支接上受击逃跑（`FleeingFromAttacker`），**逃 3 秒后停下**（可被再次攻击再逃）——「打一下→追→再打」的猎杀节奏
- **逃跑速度 4.0m/s**（< 玩家 4.3，追得上但不轻松）
- **血量**：猪 10 / 牛 15 / 鸡 4（木剑 3 下杀猪——成就感与节奏的平衡点）

## 3. 死亡掉肉（修断环③）

- **击杀路径统一**：CombatController 造成伤害后由 `MobAI` 的死亡序列接管（`Health.IsDead → Dying + LastDrops`），不再直置 Dying——m4 X1 的 `SpawnDropsForMob` 自然掉真实物品（drop_tables.json 的 porkchop/beef/chicken 已就绪）
- **击杀经验**：猪 3 / 牛 5 / 鸡 2 / 僵尸 10 → `PlayerContext.Experience` 入账 + 屏上小飘字「+N 经验」

## 4. 战斗手感四件套

| 项 | 实现 |
| --- | --- |
| 受击闪红 | mob 全部位材质闪红 0.15s（MPB 临时 tint——m8 终审确认的 MPB 逐渲染器手法，不破坏职业染色） |
| 击退 | mob 沿攻击方向冲量 1.5m（速度冲量衰减，非瞬移） |
| 命中音效 | `PlayerAudioSystem` 加一条打击音（复用既有音频资源，没有则程序生成短促打击声/变调既有音） |
| 击杀动画 | mob 死亡 0.3s 缩小消失（替代瞬间消失；Dying 计时已有，接缩放） |

## 5. 测试与验收

**自动化（EditMode）**：空手攻击判定/武器伤害差异表/冷却节流/受击逃跑 3s 停/逃跑速度 4.0/血量表/死亡走 MobAI 序列（LastDrops 非空）/经验入账数值/击退冲量方向与衰减/闪红 0.15s 复原/缩小动画时长。

**实机验收剧本**：
1. 空手打死一只鸡（4 下）→ 掉鸡肉 → 捡起
2. 木剑杀猪：3 下，每下闪红+击退+命中音，最后「+3 经验」飘字、缩小消失、掉猪肉
3. 吃猪肉恢复饥饿
4. **全闭环**：挖矿→合成木剑→猎杀→吃肉——孩子独立跑通即验收

## 与既有约束的关系

- Core 零 UnityEngine（逃跑状态/血量/经验在 Core；闪红/击退视觉/音效在 Unity 层）
- 复用单一真源：伤害走 `Mob.Health`（Core 序列）、掉落走 `SpawnDropsForMob`、经验走 `Experience`、音效走 `PlayerAudioSystem`
- 注释/断言中文；数据（武器伤害）读 items/*.json 现有字段不新增 schema
