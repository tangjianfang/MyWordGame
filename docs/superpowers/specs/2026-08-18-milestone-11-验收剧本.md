# milestone-11 验收剧本（给孩子的实机关卡 · 2026-08-18）

> 配合 build-and-run.sh 出包后逐关游玩。每关都有「机器已断言背书」，打勾只看手感与好玩。
> 前置：全新世界（旧档兼容但新内容要新探索才能遇到）。

## 第一关 · 新世界新面孔（生物多样性）

1. 走进平原：**羊群**（做床的毛来源）、兔子；森林里有狐狸/鹿/浣熊，运气好见到**熊猫**
2. 雪原：**企鹅**摇摆、松树雪松成林；山上山羊、巨杉
3. 夜晚别出门：**骷髅会射箭**（听弓声）、**蜘蛛**追人、**苦力怕**靠近会嘶嘶响然后砰！
4. 机器断言：17 生物模型/spawn 规则/掉落表全过守卫测试

## 第二关 · 从一块草地到面包（农业闭环）

1. 徒手打高草 → 有概率掉**小麦种子**（30%）
2. 木板做**锄头**，右键草地变耕地；种子种上；旁边放水更好（湿地长得快）
3. 等它变金黄 → 打碎收小麦+种子；小麦做面包
4. 手持小麦/甜菜右键两只牛/羊 → 它们会生小宝宝！
5. 机器断言：FarmSystem 生长/收获/繁殖/BreedingSystem 60+ 测试

## 第三关 · 安个家（建造与放置）

1. 放**箱子**存家当（27 格，Shift 整组搬）、放**床**——晚上右键睡到天亮，重生点设在这
2. **木门**两格自动放好、火把照亮屋内（地下也亮）、玻璃窗看星星
3. 椅子/桌子/笔记本电脑（屏幕会放视频！）摆满房间
4. 机器断言：通用放置路由 13 测（床/门双格原子）

## 第四关 · 武装升级（装备与附魔）

1. 挖铁做**铁盔甲**四件（背包右侧四格穿上，防御+6）
2. 书+青金石做**附魔书**，右键装备融合——锋利/效率/耐久三种光
3. **弓**：按住右键蓄力（有蓄力条），松手射箭；杀骷髅报仇
4. 机器断言：盔甲双源属性 36 测 + 附魔编码不撞耐久 65 测

## 第五关 · 任务与村庄（引导链）

1. 跟着任务提示走完第一章 → 弹出「第二章已解锁」
2. 第二章 8 步：睡觉→种地→收获→喂羊→铁甲→附魔→弓杀骷髅→击退苦力怕
3. 找到**村庄**（平原/森林，约 20 格一村的密度）：小楼、水井、村民聚堆、可以交易
4. 机器断言：双章任务链 39 测 + 村庄生成蓝图逐格校验

## 第六关 · 终局 Boss（机元守卫）

1. 挖到 y<16 深处找**机元矿石**（最稀有！钻石镐才挖得动）；挖矿有 15% 额外掉**矿石方块**
2. 把 4 块矿石方块摆成 2×2，右键——**机元守卫**苏醒！（2.5 格紫金机甲巨人）
3. 躲它的冲撞和震荡波，半血它会召唤骷髅！打倒它掉**下界合金锭**+锋利 III 附魔书
4. 下界合金锭+铁盔甲 → 合成**下界合金盔甲**（防御翻倍）——最强装备达成！
5. 机器断言：Boss 三招状态机 36 测

## 第七关 · 氛围与彩蛋

1. 等一场**雨**（雪原下雪）；抬头看**云**慢慢飘
2. 挖方块有碎屑飞溅、爆炸有火光帧、附魔有光柱
3. 太难了？设置面板开**和平模式**（怪不刷、死了不掉东西——其实本来就不掉，保险）
4. 主菜单有视频背景；BGM 白天晚上不一样（av 赛道出品）
