## 关键设计决策

### 飞行（创造式）

- 触发：**双击空格**（间隔 <0.3s）切换飞行态，F 键等效；HUD 提示「飞行：开/关」
- 飞行中：空格升 / Shift（左）降 / WASD 平移（速度 8m/s，为走速 ~1.9 倍），无重力、掉落伤害豁免
- 退出：再双击空格 / 触地 / F；退出后恢复正常物理
- 存档不记飞行态（重进世界默认步行）

### 血条与难度

- 血条：`MobView` 头顶 2D 条（宽=体型、红底+绿前景），受击显示 3s 淡出；Boss（机元守卫）常显+大号；宝宝模式与普通模式共用
- 难度：`PeaceMode` 同款静态开关模式新增 `DifficultyMode`（设置面板三档：宝宝=怪 1 血 / 普通=现值；敌对伤害不变——只调怪血，不动别的）——孩子的"一级血"在宝宝档完整保留

### 远程武器参数化

- items 表新增 `range`（米）字段：弓 60 / 火枪 25 / 骷髅箭沿用射手 AI；`attackDamage` 已有
- 箭实体按发射武器 `range` 决定最大飞行距离（超程消亡）；弓保留重力抛物线、枪直射无重力（装填 1.5s、声音大惊怪）
- 火枪新物品 + 配方（铁锭×2+木板×2+火药×1）+ 子弹物品（铁锭×1→4 发）——火药来源=苦力怕掉落（m11 已通）

### 合成诊断（P0）

- 复现路径清单：口袋 2x2 vs 工作台 3x3 各试「木板→工作台」「圆石→熔炉」「铁锭→铁镐」；新 m11/m12 物品（家具/盔甲/锄）在两个 UI 里的表现；SHIFT 移动物品进/出网格
- 三种假设：UI 点击入格 bug / 新物品配方缺失（家具等设计上无配方——若是此项则属「预期行为需教学」而非 bug）/ `RecipeDatabase.FindMatch` 排序回归（③改过排序）
- 产出：复现步骤 + 根因 + 修复或教学文案

## 非目标（YAGNI）

- 枪械树扩展（步枪/狙击/连发）——先一把火枪验证手感
- 飞行动画/翅膀造型
- 弹药 HUD 独立面板（hotbar 角标够用）

## 测试与验收

- 自动化：飞行状态机（切换/六向速度/触地退出/掉落豁免）、血条显隐计时、难度血量缩放、武器射程参数、UI 点外关闭统一行为、合成诊断的回归测试（视根因）
- 实机验收剧本（给孩子）：双击空格飞上天俯瞰村庄→落地；用弓 60m 外射猪→猪头顶冒血条→死掉腐肉（给他看"早就有啦"）；换宝宝难度→僵尸一箭嗝；R 面板三武器切换；火枪轰苦力怕捡火药；背包点外面自动关
