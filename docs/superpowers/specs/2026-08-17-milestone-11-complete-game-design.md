## 2. 架构：三注册表外置（第 0 波，串行小任务）

并行的前提是消除热点文件。三个基建任务各自独立、互不触碰：

### A. 生物造型表外置

`Assets/Scripts/Unity/Rendering/MobModels.cs` 部位表（C# 常量）→ `Assets/StreamingAssets/mobs/models/*.json`。
坐标约定不变（脚底中心为原点、面朝 +Z）。加载器 + 守卫测试（原 EditMode 断言表的测试改为断言 JSON 加载结果）。
**解锁**：加生物 = 1 个 JSON + `spawn_rules.json` 一行，不动 C#。

### B. 植被特征表外置

`TreeFeature` 参数化 → `Assets/StreamingAssets/vegetation/*.json`：
树形（高/冠幅/叶密度/分层形状/绑定的原木与树叶方块 id）+ 花草（贴图/碰撞/群系/密度）。
确定性生成性质不变（世界坐标哈希）。**解锁**：树 8 种、花草 12 种全是 JSON。

### C. 存档 schema 一次性扩展

`level.dat` 预留字段：箱子内容、床重生点、附魔、成就统计、农业状态。一次 bump `FormatVersion`，
旧档缺字段 = 全新开始（沿用 quests 的兼容策略）。**解锁**：各系统并行写各自字段。

## 3. 五波执行结构

```
第0波(串行,~1天)   A/B/C 三注册表基建 + 工具脚本扩展（--tree/--variants/ASSETS）
      ↓
第1波(全并行,~2天)  内容量产 6 赛道（战斗/动物/植被/方块/家具/农业）——全是 JSON + 贴图 + 少量胶水
      ↓  集成点①：串行接线批（WorldBootstrap/BlockInteraction）+ dotnet 全绿 + EditMode 全绿
第2波(全并行,~2天)  系统串联：盔甲/附魔/床/箱子UI/任务第二章/农业链
      ↓  集成点②
第3波(全并行,~1天)  世界内容：村庄/Boss/下界合金 + 氛围四件套（BGM/天气/云/粒子）
      ↓  终审 + 一次修复波 + 给孩子的验收剧本
美术波(贯穿全程)    提示词需求文件 → generate_art.py 批量生成 → 后处理 → 验收入库
```

**热点文件分配规则**（并行冲突消解）：

| 热点文件 | 归属 |
| --- | --- |
| `WorldBootstrap.cs` / `BlockInteraction.cs` | 只在集成点由串行接线批修改，并行期禁改 |
| `MobModels`（外置后为 mobs/models/*.json） | 每个 biome/物种一个文件，天然并行 |
| `postprocess_art.py` / `generate_art.py` | 第 0 波工具脚本任务独占；美术提示词任务只写 `art/requests/**/*.md` |
| `spawn_rules.json` / `biomes.json` | 跨表 JSON：每赛道改自己的条目，集成点复核跨表引用测试 |
| Core 各子系统 | 按 赛道→子系统 一一对应，一个子系统同一时间只有一个 owner |

**流程双路径**：第 1 波 JSON 量产与美术提示词走**轻量路径**（TDD + 单次评审，跳过完整 SDD）；
第 0 波基建、第 2-3 波系统串联走**完整路径**（spec 已有 → plan 任务卡 → 子代理实现 → 评审 → 修复轮）。

## 4. 美术管线（12 大类 · 48 子类 · ~392 张）

全量树 v2（已经用户确认）以 `art/requests/` 目录结构为准：12 大类 = blocks/items/entities/player/sky/ui
六个既有目录 + effects/scenes/codex/architecture/marketing/seasonal 六个新目录。每个子类一个子目录或
前缀批次文件，每叶一份 `.md`（八段格式：用途/规格/调色板/视觉描述/AI 提示词/负面提示词/后处理/验收）。

**四个新模板**：
- 帧序列模板（effects/）：一提示词生成动作关键帧，后处理拆帧对齐
- 大图插画模板（scenes/）：不做无缝、不降到 32，直接 1024 使用
- 徽章模板（codex/成就）：圆形底盘 + 前景主题词，16 成就换前景
- 调色板量产模板（染色系等 ~40 张变体）：AI 生成 1 张母版，后处理程序换色，省 ~80% 调用

**分档执行**：
- P0 ~120 张（阻塞玩法）：功能方块/农业/花草/树木/盔甲/武器/敌对生物/UI 系统——跟随第 1-2 波
- P1 ~130 张（质量感）：动物/特效/图鉴/场景/染色——跟随第 3 波
- P2 ~140 张（锦上添花）：节日/宣传/奇幻生物/季节变体——穿插空闲

**执行顺序（用户指定）**：先写全部提示词需求文件（并行子代理）→ 再跑
`python tools/generate_art.py --only <批次> --n 4`（API key 走 .env，不入仓库）→
`postprocess_art.py` 后处理 → 对照验收清单 → 入库 `Assets/` 并更新 `art/README.md` 索引。

**工具脚本增量**（第 0 波任务）：
1. `postprocess_art.py` ASSETS 清单扩充全部新资源（名字/最终尺寸/调色板——两脚本共用）
2. `generate_art.py --tree`：打印 12 大类树 + 每叶状态（已入库/有需求/incoming 有图/未生成）
3. `--variants`：母版换色批处理（染色羊毛 16 色等）
