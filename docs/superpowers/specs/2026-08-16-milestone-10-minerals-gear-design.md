## 2. 镐耐久与碎裂（孩子的原创机制）

- **耐久**（MC 原值）：木镐 59 / 石镐 131 / 铁镐 250 / 钻石镐封顶 255（8 位 Metadata 编码约束）次；每挖一次 -1（`ItemStack.Metadata` 耐久字段已在，m3 就预留了——启用它）
- **碎裂**：耐久尽 → 镐消失 + 碎块散落（4-6 个 0.15 格小碎块——掉落物 ItemDropView 实际是 0.25 格，0.15 是碎块自己的尺寸，配色沿用其管线）+ **碎块碰到玩家 0.5 伤害（0.6m 接触半径；fix1：同一次碎裂共享一次伤害，站定最多掉 0.5）、2 秒后消失**（孩子的设定，伤害很低不挫败）
- 耐久 UI：hotbar 图标上叠耐久条（宽=剩余比例，绿→红）

## 3. 装备属性系统（四材料专属）

| 材料 | 装备件 | 属性 | 数值 |
| --- | --- | --- | --- |
| 金 | 金剑/金镐等既有金装备 | 攻击 | +1/件（叠加在武器 attackDamage 上） |
| 粗铁→铁锭 | 铁剑/铁镐/铁斧 | **防御**（新属性：伤害减免） | +1/件（手持即计——简化模型，不做穿戴栏） |
| 夏季合金 | 合金剑/合金镐（新配方） | **移速**（新属性） | +5%/件 |
| 机元 | 机元剑/机元镐（新配方） | **生命上限** | +2/件 |

- 简化模型：**手持该材料装备即生效**（不做穿戴栏——属性挂在选中物品上，切走即失效，直觉且实现小）
- **升级**：同材料 2 件 → 1 件强一级（+1→+2），即时合成，配方进 recipes/*.json
- **防御/移速两个新玩家属性**：`PlayerContext` 加 `Defense`（伤害减免，TakeDamage 处减伤）/ `MoveSpeedBonus`（PlayerMotor 速度乘数）——由手持装备每帧刷新

## 5. 测试与验收

**自动化**：
- dotnet：工具门槛矩阵（minToolTier 判定/挖了不掉）、耐久递减与碎裂触发、防御减伤/移速乘数/生命上限 Core 计算、升级配方合成
- EditMode：矿石生成确定性（同 seed 同位置同矿）、碎块 0.5 伤害 2s 消失、耐久 UI 比例、右键复活路由
- 基线 dotnet 489 / EditMode 861 只增不减

**实机验收剧本（给孩子）**：
1. 徒手挖石头：慢且不掉（孩子自己的规则！）
2. 木镐→石镐→挖到铁→熔炉炼铁锭→铁镐
3. 铁镐挖到金矿/夏季合金→做金剑（攻击+1）
4. 挖穿地层深处找到机元（最稀有）→生命上限+2
5. 用一把旧木镐挖到耐久尽：碎裂！碎块扎脚（0.5 伤）
6. 死了按右键复活，满血
