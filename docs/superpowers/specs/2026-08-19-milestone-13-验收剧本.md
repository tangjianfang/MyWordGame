## 第一关 · 飞起来（飞行系统 · 孩子原话第 3-4 行）

**实操**：
1. 进世界，找开阔地
2. **双击空格**（<0.3 秒内点两下）—— HUD 应弹出「飞行：开」
3. 持续按空格 → 持续上升；按 Shift → 持续下降；WASD → 平移（8m/s）

## 第三关 · 宝宝难度一击必杀（难度系统 · 孩子原话第 7 行）

**实操**：
1. 按 H 打开帮助菜单 → 「设置」页签 → 找「和平模式」toggle 之下新加的「难度」行
2. **点「开启 宝宝模式」** → 关掉帮助菜单
3. 夜晚找僵尸 → 弓射 1 箭 → **一击嗝**（腐肉 0-2@50% + 经验 10）
4. 找猪/牛/鸡 → 同样一击必杀
5. 找机元守卫 → 也一击必杀（宝宝模式不限 Boss）
6. 切回「普通」→ 僵尸要射 3-4 箭才死（现值 20 血）

**机器断言**：W2 commit 5 个 BabyModeTakeHitTests（僵尸/猪/Boss 一击必杀/普通档不变/重置）。

## 第四关 · 火枪！远程高伤直射（远程武器参数化 · 孩子原话第 5-6 行）

**实操**：
1. 工作台合成**火枪**（铁锭 2 + 木板 2 + 火药 1 = 3×3）
2. 工作台合成**子弹**（铁锭 1 → 4 颗）
3. 火药来源 = 苦力怕掉落（找苦力怕让它靠近你然后自己爆炸）—— 真的会有火药掉！
4. 手持火枪 → **按 R 键**打开武器面板（看 m13 W4）→ 列表应包含火枪 + 子弹数
5. 选中火枪 → 按左键 → **直射**打出子弹（无蓄力、无抛物线、25m 内直线命中）
6. 立即再按左键 → **咔哒**（无弹不开火/装填中）
7. 等 1.5s 装填 → 再按左键 → 命中
8. 找骷髅（射手 AI）→ 它射你 60m 抛物线箭 → 你射它 25m 直射子弹（射程短但伤高 6）

## 第六关 · 点外面自动关（模态 UI 点外关闭 · 孩子原话第 9 行后段）

**实操**：
1. 按 E 开背包 → 鼠标移到背包**外面**点击 → 背包应**自动关闭**
2. 按 P 开工作台 → 外面点击 → 工作台应自动关闭
3. 放箱子右键开 → 外面点击 → 箱子应自动关闭
4. 放穿戴装备的 4 槽 UI（m11 穿戴栏）→ 外面点击 → 自动关闭
5. 按 R 开武器面板 → 外面点击 → 自动关闭
6. **SHIFT + 点击主背包物品**：必须**先于**点外关闭判断——把材料送进合成区，不应触发关闭

**机器断言**：W4 commit 加 `ModalCloseOutsideTests`（5 个 UI 逐一断言 click-outside close
+ SHIFT+click 优先级）。

**实现细节**：方案 A（每 UI 自管 mouseDown 位置 + `!IsInsideRect(mousePos, uiRect)` 关闭），
不引 `ModalUiManager`。5 个 UI 都暴露 `BackgroundBounds` 属性供 EditMode 断言。

## 第七关 · 视频循环丝滑 + BGM 滑条（av 升级）

**实操**：
1. **退出游戏回主菜单** → 看主菜单背景视频（menu-bg.mp4）
2. 旧版 1366×768 / 新版 1920×1080（实测升级 1.94×像素）
3. **等 6 秒** —— 视频循环点应**几乎察觉不到**（末帧 vs 首帧 RMSE 从 0.20 → 0.097）
4. 按 H 打开帮助菜单 → 「设置」页签 → 拖动「音乐音量」滑条到 0 → BGM 应静音
5. 拖到 100 → BGM 应最大
6. 「音量」滑条拖到 0 → 全静音（含 BGM + 环境 + 音效）
7. 「音量」滑条回 80 / 「音乐音量」回 80 → 默认

**机器断言**：视频管线层（`tools/generate_media.py`）：MiniMax API 768P → 1080P +
ffmpeg crf 18 + 1920×1080 上采样兜底 + 0.6s alpha overlay 无缝循环 fade；
Unity RT：TitleScreenUi 1280×720 → 1920×1080 / VideoScreenSystem 320×180 → 640×360。
BGM 滑条：SettingsPanelUi → MusicVolumeBus → BgmAudioSystem/AmbientAudioSystem
wiring 闭环（dot doc + EditMode 测试守护）。

⚠ **可能的风险**（实机才能验证）：
- 主菜单视频 RT 升到 1920×1080 后**可能更掉帧**（GPU 工作量增）。若出现，
  调低 RT 至 1600×900 兜底。
- "音乐音量"与"音量"分层是否体感清晰（既可独立调 BGM 又可全静音）。
