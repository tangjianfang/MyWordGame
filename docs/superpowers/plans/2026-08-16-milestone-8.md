public static MobPart[] Build(MobKind kind)

**Interfaces:**

- [ ] **Step 1: 写失败测试**——拼装后 `transform.childCount == Build(kind).Length`；五生物逐个 TestCase；host cube Renderer `enabled == false`；`SetWalkPhase(0..2π)` 时腿局部旋转角 ∈ [-20°, 20°] 且对角腿（LegPhase 差 π）反向；非腿部位不受 phase 影响
- [ ] **Step 2: 确认失败 → Step 3: 实现**：

```csharp
// MobView 核心：部位 cube + 腿部铰链（cube 挂在枢轴下、几何下移补偿——经典手法）
foreach (var part in MobModels.Build(_kind))
{
    var pivot = new GameObject(part.Name);          // 腿枢轴在腿顶部
    pivot.transform.SetParent(transform, false);
    pivot.transform.localPosition = part.LocalPosition + (part.IsLeg ? Vector3.up * part.Size.y * 0.5f : Vector3.zero);
    var cube = GameObject.CreatePrimitive(PrimitiveType.Cube);
    cube.transform.SetParent(pivot.transform, false);
    cube.transform.localScale = part.Size;
    cube.transform.localPosition = part.IsLeg ? Vector3.down * part.Size.y * 0.5f : Vector3.zero;
    cube.GetComponent<Renderer>().sharedMaterial = UrpMaterialFactory.CreateLit(part.Color);
}
// SetWalkPhase：_legs[i].localRotation = Quaternion.Euler(Mathf.Sin(phase + legPhase) * 20f, 0, 0)
```

朝向：MobView 若已有移动朝向则对齐「面朝 +Z」语义；没有则按 Mob 速度 `LookRotation`（读 MobView 现状决定，报告注明）。walkPhase 驱动：MobManager.Update 里按 `mob.Position` 帧间位移累计（`phase += 位移 × 8f`，站定不增、自然归位由 sin 过零——或站定时 phase 缓动到最近的 π 整数倍，选简者）。
