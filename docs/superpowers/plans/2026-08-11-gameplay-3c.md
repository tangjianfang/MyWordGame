# Gameplay 层实施计划（里程碑 3 · Plan-3C）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把世界从"有内容"做成"完整可玩"——村民 + 交易、经验 + 附魔 + 耐久、第三人称 + 模型 + 动画、玩家死亡画面 + 复活动画。

**Architecture:** Core 加 Villager / Experience / Enchanting 三个 namespace；Unity 侧加 3D 模型（用 cube 拼、避免外部资源）、UGUI 替换 IMGUI（可选）。

**Tech Stack:** C# 9 / netstandard2.1（Core）、Unity 2022.3.62f3c1 + URP 14.0.11、NUnit。

## 文件结构

### Core 层新建（`Assets/Scripts/Core/`）

| 文件 | 职责 |
| --- | --- |
| `Entities/Villager.cs` | 村民数据结构（profession / tradeOffers / 名字） |
| `Entities/VillagerAI.cs` | 村民 AI：白天站岗、晚上回家 |
| `Entities/Trade.cs` + `TradeOffer.cs` | 交易：1 物品 → 1 物品 |
| `Entities/Experience.cs` | 经验条 + 等级（0-100 升 1 级） |
| `Entities/Enchantment.cs` + `EnchantingTable.cs` | 附魔系统（简化：随机加 1-3 个属性） |
| `Entities/Durability.cs` | 工具耐久：每次用掉 1 点，0 时消失 |
| `Entities/DeathSystem.cs` | 玩家死亡状态：Respawn 计时 + 掉落 |

### Unity 层新建

| 文件 | 职责 |
| --- | --- |
| `Combat/VillagerView.cs` | 村民 cube 渲染（戴棕色头巾） |
| `UI/ExperienceBarUI.cs` | 绿色经验条 |
| `UI/DeathScreenUi.cs` | 死亡画面 5 秒后点 "复活" |
| `UI/TradeUi.cs` | 交易窗口 |
| `Player/PlayerModel.cs` | 第三人称身体（cube 拼） |
| `Player/CameraThirdPerson.cs` | 第三人称相机 |

### Assets 新增

- `Assets/StreamingAssets/items/`：emerald、book、enchanted_book、anvil、bed

## 实施阶段

### Task 1：经验 + 耐久
- **Task 1.1** `Core/Entities/Experience.cs` + 测试
- **Task 1.2** `Core/Entities/Durability.cs` + 测试（合并进 `ItemDefinition`）
- **Task 1.3** 攻击时按 kill 经验掉（僵尸 5 / 骷髅 5 / 苦力怕 5 / 猪 1）
- **Task 1.4** `UI/ExperienceBarUI.cs` 屏幕底部绿条

### Task 2：附魔
- **Task 2.1** `Core/Entities/Enchantment.cs`：附魔类型（锋利/耐久/击退）
- **Task 2.2** `Core/Entities/EnchantingTable.cs`：用经验 + 青金石随机附魔
- **Task 2.3** JSON 加 enchanted_book + anvil

### Task 3：村民 + 交易
- **Task 3.1** `Core/Entities/Villager.cs` + `VillagerAI.cs` + `Trade.cs`
- **Task 3.2** `Combat/VillagerView.cs` cube 渲染
- **Task 3.3** `UI/TradeUi.cs` 玩家右键村民弹出
- **Task 3.4** `MobManager` 白天生成村民（村庄概念简化为 3-5 只一群）

### Task 4：死亡 + 复活
- **Task 4.1** `Core/Entities/DeathSystem.cs` + 测试
- **Task 4.2** `UI/DeathScreenUi.cs` 5 秒红色 "你死了"，点复活回到出生点
- **Task 4.3** 死亡时掉光 inventory（已 plan-3a 简化：把物品丢在地上 cube 化）

### Task 5：第三人称
- **Task 5.1** `Player/PlayerModel.cs` cube 拼身体（头/身/手/脚）
- **Task 5.2** `Player/CameraThirdPerson.cs` 按 F5 切 1st/3rd
- **Task 5.3** 第三人称时玩家身体跟随 yaw

## 风险

- IMGUI 写经验条 + 死亡画面可能太丑，plan-3c 升级到 UGUI Canvas（成本 ↑）
- 附魔完全随机，玩家可能附出无用属性
- 第三人称相机与碰撞：相机可能穿墙（plan-3d 再做相机碰撞）
