# milestone-9 战斗手感与打猎闭环 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修好打猎三断环（空手可打/动物可追/打死掉肉）+ 战斗手感四件套（闪红/击退/音效/击杀动画）+ 武器伤害差异 + 击杀经验——挖→合→打猎→吃 全闭环。

**Architecture:** 两阶段：A 打猎闭环（攻击判定分流→动物逃跑重平衡→死亡统一序列）→ B 手感与验收（四件套反馈→实机验收）。全部在既有系统的缝内改造，无新架构。

**Tech Stack:** Core netstandard2.1/C#9（逃跑/血量/经验）、Unity 2022.3（射线判定/MPB 闪红/音频）、dotnet 9 + EditMode 双链。

**Spec:** `docs/superpowers/specs/2026-08-16-milestone-9-combat-design.md`
