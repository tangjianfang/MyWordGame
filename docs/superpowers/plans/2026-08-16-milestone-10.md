- [ ] **Step 1-5: TDD**；实现参考（稀有度阈值示意，数值可调报告说明）：

```csharp
public static ushort OreAt(int seed, int x, int y, int z)
{
    uint h = Hash(seed, x, y, z);          // FNV-1a，同 ValueNoise2D 风格
    if (y < 16 && h % 400 == 0) return BlockIds.MachineEssenceOre;
    if (y < 24 && h % 120 == 0) return BlockIds.SummerAlloyOre;
    if (y < 32 && h % 90  == 0) return BlockIds.GoldOre;
    if (y < 48 && h % 60  == 0) return BlockIds.RawIronOre;
    return BlockIds.Stone;
}
```

（`FillColumn` 石头分支改调 `OreAt`；Preview 字形表加四矿字符。）Commit：`worldgen: 石层嵌四矿（确定性哈希）（m10 A2）`
