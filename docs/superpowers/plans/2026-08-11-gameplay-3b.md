# Gameplay 层实施计划（里程碑 3 · Plan-3B）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 plan-3a 的基础上把世界从"能玩"做成"有内容"——树生成（橡木/桦木）、更多敌对生物（骷髅/苦力怕）、红石简易电路（拉杆/按钮/铁门/红石粉）、更多合成配方（镐/斧/锹 + 家具全套）。

**Architecture:** Core 侧加 TreeFeature / RedstoneCircuit / 更多 mob；JSON 加物品 + 配方 + 方块；Unity 侧加更多 MobView 模板（骷髅白骨 / 苦力怕绿）、红石门交互。

**Tech Stack:** C# 9 / netstandard2.1（Core）、Unity 2022.3.62f3c1 + URP 14.0.11、NUnit、IMGUI。

## 实施阶段

### Task 1：树生成（Core + Unity）
- **Task 1.1** `Core/WorldGen/TreeFeature.cs` + 测试
  - `TreeFeature.Generate(world, seed, x, y, z)`：5-7 高 log + 3 层 leaves 圆盘
- **Task 1.2** 在 `WorldGenerator.Generate` 末尾按概率调用 TreeFeature
- **Task 1.3** `Environment/SaplingGrowth.cs`：玩家右键 sapling → 调 TreeFeature

### Task 2：更多敌对 mob
- **Task 2.1** `Core/Entities/Mob.cs` 加 `MobTypeId=4=skeleton, 5=creeper`
- **Task 2.2** `Core/Entities/MobAI.cs` 加 skeleton（远程，1.5 格击退）+ creeper（3 格内自爆，2 秒延迟）
- **Task 2.3** `Unity/Combat/MobView.cs` 加更多颜色模板 + 简单模型（cube 拼）
- **Task 2.4** `Unity/Combat/MobManager.cs` 加夜晚 creeper + skeleton 生成

### Task 3：红石
- **Task 3.1** `Core/Entities/RedstoneNode.cs` + `RedstoneCircuit.cs` + 测试
  - 红石粉放置时 1 个 tick 充能；lev-er 翻动时强充能（15）；衰减到 0 删除
- **Task 3.2** `Core/Entities/DoorController.cs` + 测试
  - 铁门通过 channel 接收红石信号
- **Task 3.3** `Unity/World/RedstonePlacement.cs` 玩家右键 lever/door 触发
- **Task 3.4** `Unity/UI/RedstoneUi.cs` 调试时画线框（按 F3）

### Task 4：更多配方
- **Task 4.1** `tools/scripts/gen-gameplay-assets.py` 加 12 个新配方 + 12 个新物品
- **Task 4.2** 6 把镐（wood/stone/iron/diamond/netherite/bedrock）
- **Task 4.3** 3 把斧（wood/stone/iron）
- **Task 4.4** 3 把锹
- **Task 4.5** 7 件家具配方（workbench 2×2 占位即可）

### Task 5：Bootstrap 集成
- **Task 5.1** 加载更多方块/物品/配方
- **Task 5.2** 注册树苗右键事件

## 风险

- 树生成位置可能与现有方块冲突（叶冠可能盖住悬崖）—— 简单兜底：覆盖空气才放
- 红石电路是简化版（只支持 4 邻居，1 通道），不模拟复杂逻辑
- creeper 自爆对玩家范围伤害需要 coroutine 延迟，Unity 时间相关
